Proposals from a replay of the last 30 days: $9.90 at list prices, 613 model calls.
A replay prices the same calls again with one thing changed. The amounts overlap, so they do not add up.

1. Cap the shell output that Claude reads inline at 10,000 characters: $0.11 less, 1% of the total
   Why:  5 results of shell commands that worked were longer than 10,000 characters. Entering and carried on the later calls, they cost $0.14. With the cap Claude gets a preview of 2,000 characters and the path of a file instead, and the replay keeps only that share.
   How:  One setting in Claude Code: "bashOutputMaxChars": 10000. Claude Code then gives Claude at most 10,000 characters of a successful command's output (about 30,000 without the setting). Longer output goes to a file, and Claude reads it when it needs the rest. It needs Claude Code 2.1.261 or later.
   Risk: Claude reads the file when it needs more of the output, and each read is a tool call with a result of its own. The replay does not count those reads, so the saving is the most it can be. The setting also sets the window of output that Claude Code reads back, and the excerpt of a failed command is cut from that window: with a smaller cap, a long error can show less of its output.
   Apply: widal apply bash-output-cap --chars 10000
